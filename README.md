# alexs-pilot-profile

**_View this project:_** [https://alexstevensonpilot.netlify.app/](https://alexstevensonpilot.netlify.app/)

## Description

Coded in HTML and CSS with Bootstrap, this website is a professional profile for Alex S., a helicopter pilot. The design is original, accessible, and fully responsive across mobile devices, tablets, and desktops. It features a dark-mode palette, two aviation-related animations from LottieFiles, embedded flight footage from YouTube, and a downloadable resumé.

## Accessibility

This website was designed conscientiously with digital accessibility in mind for those with visual, auditory, motor, and/or cognitive disabilities or sensory impairments. Every effort was made to use best practices where feasible.

Ratings by Lighthouse Audit:

- Desktop: Performance 99/100 | Accessibility 96/100 | SEO 100/100
